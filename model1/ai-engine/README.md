# NonStock AI Engine

Research and intelligence engine for the NonStock project.

## Vision

Build an explainable AI market intelligence system capable of:

- Technical analysis
- Fundamental analysis
- News and event analysis
- Market structure analysis
- Cross-asset relationship analysis
- Market regime detection
- Price and return forecasting
- Risk and uncertainty estimation
- Trading decision support
- Explainable market reasoning
- JARVIS-style market intelligence

## Architecture

Data
→ Processing
→ Feature Engineering
→ Technical Intelligence
→ Fundamental Intelligence
→ News/Event Intelligence
→ Market Graph
→ Temporal Models
→ Multimodal Fusion
→ Risk Engine
→ Decision Engine
→ Explanation Engine

## Research Principle

Every model must be compared against strong baselines using
out-of-sample and walk-forward evaluation.
